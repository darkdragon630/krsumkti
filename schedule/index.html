Masuk dengan NIM

Ketik NIM dan password kamu. Kalau NIM ini belum pernah dipakai, akun baru akan otomatis dibuat dengan password yang kamu ketik — jadi cukup ingat NIM & password ini untuk simulasi berikutnya, di device manapun. Data jadwal mata kuliah otomatis dimuat dari database setelah kamu masuk.

Catatan keamanan: password disimpan sebagai hash SHA-256 di Supabase, bukan Supabase Auth penuh — jangan pakai password yang sama dengan akun penting lain.
